ShakespeareGPT

ShakespeareGPT is a character-level language model built from scratch using PyTorch. Based on the GPT architecture, the model uses a decoder-only Transformer to generate original Shakespeare-style dialogue from user prompts.

Built with Python, PyTorch, FastAPI, HTML, CSS, and JavaScript, the model contains 10.7 million parameters and was trained on Shakespeare's writing. It features 6 Transformer layers, 6 attention heads, causal self-attention, and autoregressive text generation.

The application is deployed using a FastAPI backend hosted on Render, allowing users to interact with the trained model through a live web interface. The model achieved a validation perplexity of 4.34, outperforming a bigram baseline with a perplexity of 12.44.
